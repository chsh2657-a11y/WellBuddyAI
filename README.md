# 보가드 SEO 블로그 비서 (크롬 확장 프로그램)

보가드팩토리의 「문제 해결형 SEO 검색 블로그 비서」를 크롬 사이드패널에서 바로 쓰는 확장 프로그램입니다.

뉴스 기사, 링크 또는 이슈를 넣으면 독자가 이어서 검색할 질문을 찾아 **검색형 제목 5개**를 추천합니다. 제목을 고르면 최신 공식 정보를 확인해 **AI 썸네일 1장과 FAQ가 들어간 존댓말 포스팅**을 완성합니다. 글을 보신 뒤 원하는 방향을 고르면 **본문 이미지 4장**을 관련 소제목 바로 아래에 넣어 드립니다.

## 진행 흐름

| 단계 | 하는 일 |
|---|---|
| 1. 제목 추천 | 입력 자료 확인(링크는 원문 읽기) → 구글·네이버 **실제 자동완성** 수집 → 웹 검색으로 검색 결과 확인 → 제목 5개 + 가장 추천하는 제목 1개 |
| 2. 포스팅 완성 | 선택한 제목으로 최신 공식 자료 조사 → [SEO 설정] + 완성 포스팅(도입·본문·마무리·FAQ·해시태그 15개·출처 및 확인 기준) → AI 썸네일 1장을 H1 바로 아래에 배치 |
| 3. 본문 이미지 | ① 설명형 인포그래픽 ② 관련 실사진 ③ 혼합 중 선택 → 관련 H2 바로 아래에 배치한 완성본 |

- 키워드 확인 근거는 사실대로 표시됩니다. 확장 프로그램이 직접 받아온 자동완성만 ‘자동완성 확인’으로, 웹 검색에서 본 표현만 ‘검색 결과 확인’으로 표시합니다.
- “알아서 골라서 작성”을 누르면 제목 추천 후 가장 추천하는 제목으로 바로 작성합니다. 제목을 이미 정했다면 “제목을 이미 정하셨나요?”에 입력해 바로 2단계로 갈 수 있습니다.
- 글 완성 후 “수정 요청” 칸에 원하는 변경을 적으면 같은 형식으로 다시 고쳐 줍니다.

## 설치 방법

1. 이 저장소를 내려받습니다. (GitHub의 **Code → Download ZIP** 후 압축 해제)
2. 크롬 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 저장소 안의 **`extension` 폴더**를 선택합니다.
5. 툴바의 퍼즐 아이콘에서 「보가드 SEO 블로그 비서」를 고정하면 편합니다. (단축키 `Alt+Shift+B`)

크롬 116 이상이 필요합니다.

## 처음 설정

아이콘을 누르면 오른쪽에 사이드패널이 열리고, 처음에는 설정 화면이 나옵니다.

| 항목 | 설명 |
|---|---|
| Anthropic API 키 (필수) | [Anthropic 콘솔](https://console.anthropic.com/settings/keys)에서 발급합니다. 웹 검색·웹 페이지 읽기 도구를 쓰므로 콘솔에서 웹 검색 사용이 허용되어 있어야 합니다. |
| 모델 | 기본값은 Claude Opus 5.5입니다. 더 빠르고 저렴하게 쓰려면 Sonnet 5.5나 Haiku 5.5를 고를 수 있습니다. |
| 작업 깊이 | 기본 ‘깊게’. 깊을수록 자료 확인이 꼼꼼해지지만 시간이 더 걸립니다. |
| 검색 플랫폼 | 구글 / 네이버 / 둘 다. 자동완성 수집 대상이 바뀝니다. |
| 해시태그 개수·분량 | 기본 15개, 공백 포함 약 1,800~3,000자 |
| 썸네일 그림 생성 | 기본 **Claude 일러스트**(추가 키 불필요). OpenAI 또는 Google Gemini 이미지 모델을 쓰려면 해당 API 키와 모델명을 입력합니다. |
| 본문 이미지 | 기본은 “글 완성 후 물어보기”. 미리 방향을 정해 두면 글 완성 후 같은 질문 없이 바로 만듭니다. |

API 키는 이 브라우저(`chrome.storage.local`)에만 저장되며, 각 키는 해당 서비스로 보내는 요청에만 쓰입니다.

## 사용 방법

1. 기사 페이지를 연 채로 사이드패널에서 **현재 탭 기사 가져오기**를 누르거나, 페이지·선택한 문장에서 오른쪽 클릭 → **보가드 SEO 비서로 보내기**를 고릅니다. 기사 내용이나 링크를 직접 붙여 넣어도 됩니다.
   - 처음 쓰는 사이트에서 “페이지 읽기 허용”이 보이면 눌러 주세요. 기사 본문을 읽을 때만 사용합니다.
2. **검색형 제목 5개 추천받기**를 누릅니다.
3. 원하는 제목의 **이 제목으로 작성**을 누르거나 **추천으로 작성**을 누릅니다. 번호(예: `3`)나 원하는 제목을 직접 입력해도 됩니다.
4. 완성된 글 아래에서 본문 이미지 방향을 고릅니다.
5. 내보내기
   - **서식 포함 복사**: 블로그 편집기에 그대로 붙여 넣을 수 있는 HTML(이미지 포함)
   - **마크다운 복사**: 이미지는 `images/01-thumbnail.jpg`처럼 파일 이름으로 연결됩니다
   - **HTML 파일 저장**, **이미지 파일 저장**, **SEO 설정 복사**

편집기마다 붙여 넣은 이미지를 받아들이는 방식이 다릅니다. 이미지가 빠지면 ‘이미지 파일 저장’으로 받은 파일을 직접 올려 주세요.

**넓게 보기**를 누르면 같은 작업을 새 탭의 넓은 화면에서 볼 수 있습니다. 작업 내용은 자동 저장되어 패널을 닫았다 열어도 이어집니다.

## 이미지는 이렇게 만들어집니다

- **AI 썸네일**: AI가 글자 없는 배경 그림을 그리고, 확장 프로그램이 한글 문구 1~2줄을 Pretendard 글꼴로 정확하게 얹습니다(16:9, 1280×720). 캡션은 ‘AI 제작 썸네일’입니다. 선택한 이미지 모델이 실패하면 Claude 일러스트로 대신 만들고 그 사실을 알려 드립니다.
- **설명형 인포그래픽**: Claude가 본문에서 확인한 사실로 내용을 설계하고, 확장 프로그램이 표·순서·체크리스트·주의사항 형식으로 정확한 글자로 그립니다. 그림 속 숫자를 본문과 자동 대조해 맞지 않으면 한 번 고치고, 그래도 남으면 알려 드립니다. 캡션은 ‘AI 제작 설명용 인포그래픽’입니다.
- **관련 실사진**: [위키미디어 공용](https://commons.wikimedia.org/)에서 재사용 가능한 라이선스(CC0, 퍼블릭 도메인, CC BY, CC BY-SA)의 실제 사진만 찾습니다. Claude가 미리보기와 파일 정보를 보고 관련성·개인정보 노출·촬영 시점을 검수합니다. 작성자·출처·라이선스를 캡션에 표시하고, 오래된 사진은 과거 자료임을 밝힙니다. 4장을 채우지 못하면 부족한 수를 알려 드리고 인포그래픽으로 대체할지 묻습니다.

## 알아 두실 점

- 검색 노출이나 순위를 보장하지 않습니다. 게시 전에 공식 자료의 최신 공지를 한 번 더 확인해 주세요.
- 자동완성은 구글(`suggestqueries.google.com`)과 네이버(`ac.search.naver.com`)의 공개 자동완성 주소에서 받아옵니다. 조회에 실패하면 ‘자동완성 확인’ 표시를 쓰지 않고 검색 결과와 검색 의도 추론으로 진행합니다.
- 요청은 모두 브라우저에서 각 서비스로 바로 보내며, 별도 서버를 거치지 않습니다. API 사용 요금은 각 키의 계정에 청구됩니다.

## 개발자용

```
extension/            크롬에 로드하는 폴더 (빌드 과정 없음)
  manifest.json
  sidepanel.html/.css/.js   화면과 진행 로직
  background.js       사이드패널 열기, 오른쪽 클릭 메뉴
  prompts/system-prompt.md  비서 지침 원문 (수정하면 바로 반영)
  prompts/output-contract.md  확장 프로그램용 출력 규약
  lib/                Claude 호출, 자동완성, 썸네일, 인포그래픽, 실사진, 내보내기
  vendor/anthropic-sdk.mjs  공식 Anthropic SDK 브라우저 번들
  fonts/              Pretendard (SIL OFL 1.1)
tests/                단위 테스트, 확장 프로그램 E2E 테스트
```

- 비서의 말투·규칙을 바꾸려면 `extension/prompts/system-prompt.md`를 고친 뒤 `chrome://extensions`에서 새로고침하면 됩니다.
- Claude 호출은 공식 `@anthropic-ai/sdk`를 사용합니다. 버전을 올렸다면 `npm install` 후 `npm run build:vendor`로 번들을 다시 만듭니다.
- 테스트: `npm test`(단위), `npm run test:e2e`(Chromium에 확장 프로그램을 올려 모든 외부 API를 모의 응답으로 바꾼 뒤 3단계 전체를 실행, 화면은 `test-results/`에 저장)
- 기술 메모: 모든 요청은 스트리밍, 시스템 프롬프트는 프롬프트 캐싱, 웹 검색·웹 페치 서버 도구(`web_search_20260209`, `web_fetch_20260209`)와 `pause_turn` 이어받기, Opus 5.5·Sonnet 5.5에서는 서버 측 거절 대체 모델(`fallbacks: "default"`)을 사용합니다. 인포그래픽·실사진 계획은 JSON 스키마 구조화 출력으로 받습니다.
