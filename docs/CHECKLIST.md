# 개발 목표 체크리스트

[개발계획서](development-plan.md)의 로드맵을 실제 작업 순서대로 쪼갠 목록이다. 위에서 아래로 진행하며, 끝난 항목은 `- [ ]` 를 `- [x]` 로 바꾼다.

**진행 규칙**
- 항목 번호(예: `P1-08`)로 작업을 지시하거나 확인한다.
- 한 항목(또는 관련된 몇 개 항목)을 끝낼 때마다 테스트 → 커밋 → 푸시하고 체크한다.
- 단계 마지막의 **🏁 단계 완료 기준**을 모두 통과해야 다음 단계로 넘어간다.
- 👤 표시는 개발 외에 사용자가 직접 준비할 항목이다.
