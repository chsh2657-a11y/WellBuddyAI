보가드 SEO 블로그 비서 - 설치 방법
==================================

[설치]
1. 크롬 주소창에 chrome://extensions 를 입력합니다.
2. 오른쪽 위 '개발자 모드'를 켭니다.
3. '압축해제된 확장 프로그램을 로드합니다' 버튼을 누릅니다.
4. 이 README.txt와 manifest.json이 함께 들어 있는 폴더를 선택합니다.
   (윈도우에서 '모두 압축 풀기'를 했다면 다운로드\bogard-seo-extension 폴더입니다.)
5. 툴바의 퍼즐 아이콘에서 '보가드 SEO 블로그 비서'를 고정합니다.
6. 아이콘을 누르면 오른쪽에 패널이 열립니다. 설정에서 Anthropic API 키를 입력하고 저장하면 바로 쓸 수 있습니다.
   (단축키: Alt+Shift+B / API 키 발급: https://console.anthropic.com/settings/keys)

[이런 메시지가 나오면]
- "매니페스트 파일이 없거나 읽을 수 없습니다": 선택한 폴더를 열었을 때 manifest.json 파일이 바로 보여야 합니다.
  안 보이면 그 안의 폴더를 열어 manifest.json이 보이는 폴더를 선택해 주세요.
  압축 파일(.zip) 자체는 선택할 수 없으니 먼저 압축을 풀어 주세요.

[주의]
- 설치한 뒤에도 이 폴더를 지우지 마세요. 크롬이 이 폴더에서 확장 프로그램을 읽습니다.
  옮기고 싶다면 옮긴 다음 위 3~4번을 다시 하면 됩니다.

[업데이트]
- 새 압축 파일을 풀어 이 폴더를 덮어쓴 뒤 chrome://extensions 에서 새로고침(↻) 버튼을 누릅니다.
- 다른 위치에 풀었다면 그 폴더를 3~4번처럼 다시 로드하면 됩니다.
- 확장 프로그램 ID가 고정되어 있어 어느 쪽이든 API 키·설정·작업 내용이 그대로 유지됩니다.

[사용 순서]
1. 기사 페이지에서 '현재 탭 기사 가져오기'를 누르거나 오른쪽 클릭 → '보가드 SEO 비서로 보내기'
2. '검색형 제목 5개 추천받기' → 제목 선택 또는 '추천으로 작성'
3. 완성된 글 아래에서 본문 이미지 방향(인포그래픽 / 실사진 / 혼합) 선택
4. '서식 포함 복사' 또는 'HTML 파일 저장'·'이미지 파일 저장'으로 블로그에 옮기기

비서의 규칙과 말투는 prompts/system-prompt.md 파일을 고친 뒤 chrome://extensions 에서 새로고침하면 바로 반영됩니다.
